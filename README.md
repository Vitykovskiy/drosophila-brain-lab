# Drosophila Brain Lab

Репозиторий для работы с вычислительной моделью мозга дрозофилы на основе коннектома FlyWire.

Модель, ноутбуки, данные версий 630 и 783 и примеры результатов находятся в [`Drosophila_brain_model/`](Drosophila_brain_model/). Установка и использование описаны в [README модели](Drosophila_brain_model/Readme.md).

Исходная модель: [philshiu/Drosophila_brain_model](https://github.com/philshiu/Drosophila_brain_model), Philip Shiu и Nico Spiller. Исходные материалы сохранены с [лицензией MIT](Drosophila_brain_model/LICENSE).

Правила работы агентов: [AGENTS.md](AGENTS.md).
